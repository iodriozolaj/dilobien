How the A/B tests work

Test 1 — this page's headline. Half of visitors see a pain-focused headline ("you're stuck on what to say"), half see a benefit-focused one ("skip the awkward drafting"). Each page load logs an impression; clicking the CTA logs a conversion for whichever variant that visitor was assigned.

Test 2 — the homepage CTA copy. Half of homepage visitors see "Join the waitlist", half see "Get early access" on the hero and nav buttons. A conversion is logged only when the visitor actually submits the waitlist form — see the homepage for that test live.

Variant assignment and the content library are both pure, exported functions (window.MarketingEngine), so the logic the page runs is exactly what the software tests call.
